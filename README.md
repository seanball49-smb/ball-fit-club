# Ball Fit Club

A workout, food and weight tracker for two people. It runs in the phone's browser and can be added to the home screen like a normal app. There is no sign-in. Both phones read and write the same Supabase database, so each of you sees the other's updates within a second or two.

**Stack:** plain HTML, CSS and JavaScript (no build step) · Supabase (database and live updates) · GitHub (code) · Vercel (hosting)

---

## What's in this folder

| File | What it does |
|---|---|
| `index.html` | The app's page |
| `styles.css` | The look: colors, fonts, layout, light and dark mode |
| `app.js` | Everything the app does |
| `build.js` | Runs on Vercel at each deploy and fills in your Supabase keys from Vercel's Environment Variables |
| `config.js` | Placeholder only. The real one is generated by `build.js`; you never edit it |
| `supabase/schema.sql` | Creates the database tables. You run it once in Supabase |
| `manifest.webmanifest`, `icons/` | App name and icon for the home screen |
| `vercel.json` | Tells Vercel how to build the app and to always serve the newest version |

## Setup (about 20 minutes, no coding)

### Step 1: Create the database in Supabase
1. Go to **supabase.com** and sign in (signing in with GitHub is easiest).
2. Click **New project**. Name it `ball-fit-club`, create a database password and save it somewhere, and pick the region closest to you (for example **West US**). Click **Create new project** and wait about a minute.
3. In the left sidebar, open **SQL Editor** and click **New query**.
4. Open `supabase/schema.sql` from this folder in any text editor. Copy everything, paste it into the editor, and click **Run**. You should see "Success. No rows returned."
5. Optional check: open **Table Editor**. You should see `profiles`, `plans` and `days`, with 6 starter workouts in `plans`.

### Step 2: Copy your two Supabase values
1. Click **Connect** at the top of the project, or go to **Project Settings → API Keys** (on older projects it's **Project Settings → API**).
2. Copy the **Project URL**. It looks like `https://abcdefghijk.supabase.co`.
3. Copy the **publishable** key, which starts with `sb_publishable_`. If you only see legacy keys, copy the **anon public** key instead.
   - **Never use the `secret` or `service_role` key.** That key has full admin access and must not go in the app.

### Step 3: Put the code on GitHub
1. Go to **github.com** and click **+ → New repository**.
2. Name it `ball-fit-club`, set it to **Private**, and click **Create repository**.
3. On the empty repository page, click **uploading an existing file**.
4. Unzip `ball-fit-club.zip` on your computer. Open the folder, select **everything inside it** (including the `icons` and `supabase` folders), and drag it into the GitHub page. Upload the contents, not the outer folder, so that `index.html` sits at the top level of the repo.
5. Click **Commit changes**. You don't need to edit any files; your keys go into Vercel in the next step.

### Step 4: Put the app online with Vercel
1. Go to **vercel.com** and sign up with **Continue with GitHub**.
2. Click **Add New… → Project**. Find `ball-fit-club` and click **Import**. If it isn't listed, click **Adjust GitHub App Permissions** and give Vercel access to that repository.
3. Under **Framework Preset**, choose **Other**. The build settings come from `vercel.json`, so leave them as they are.
4. Open **Environment Variables** and add these two:

   | Key | Value |
   |---|---|
   | `SUPABASE_URL` | Your Project URL, like `https://abcdefghijk.supabase.co` |
   | `SUPABASE_ANON_KEY` | Your publishable key (`sb_publishable_…`) or anon public key |

5. Click **Deploy**. After about 30 seconds you'll get a link like `ball-fit-club-xyz.vercel.app`.

If you change the variables later (**Project → Settings → Environment Variables**), go to **Deployments**, open the **⋯** menu on the latest deployment, and choose **Redeploy**. The new values only take effect after a redeploy.

### Step 5: Set it up and install it on both phones
1. Open the Vercel link on **your** phone. Fill in both of your names, goals and weights, then tap **Get started**. Leave calories and protein blank if you'd like suggested numbers.
2. Tap **Sean** when it asks who's using the phone.
3. Add it to your home screen:
   - **iPhone (Safari):** tap the **Share** button → **Add to Home Screen** → **Add**.
   - **Android (Chrome):** tap the **⋮** menu → **Add to Home screen** or **Install app**.
4. Text the link to your wife. She opens it, taps her name, and adds it to her home screen the same way.

Now open the app from the home screen icon. It opens full screen, like a regular app.

## Using it day to day
- **Workouts tab:** tap **New plan** to write a workout. Choose who it's for (you, her, or both of you) and which day. It then appears on that person's **Today** screen on that day. The 6 starter plans can be edited or deleted.
- **Today:** check off exercises as you go, tap water glasses, do the daily quest, roll a bonus workout, send a high-five, and weigh in.
- **Nutrition:** use the one-tap quick adds or enter your own food. The arrows let you look at or fix past days.
- **Progress:** see the weight chart, progress toward your goal, and achievements for either of you.
- **Settings** (the sliders icon at the top) changes names, goals and targets. Tap your initial at the top to switch whose phone it is.

Every action earns XP: workouts +40, bonus workouts +30, quests +15, weigh-ins +10, foods +5, water +2. Every 300 XP is a new level.

## Making changes later
Edit any file on GitHub (pencil icon → **Commit changes**) and Vercel redeploys automatically within about a minute. Close and reopen the app on your phone to get the new version.

## About privacy
You asked for no sign-in, so the database accepts changes from anyone who has both the app's link and the key, which ships inside the app. Only share the Vercel link with each other. Nothing in here is sensitive, but if you ever want it locked down, a simple shared login can be added later using Supabase Auth.

## Troubleshooting
- **"Almost there… open config.js":** the Environment Variables are missing or misnamed in Vercel. Add `SUPABASE_URL` and `SUPABASE_ANON_KEY` exactly, then **Redeploy**.
- **"Couldn't reach your database":** check that the two Environment Variable values are pasted exactly (no spaces or quote marks), that you redeployed after adding them, and that `schema.sql` ran without errors.
- **Your partner's updates don't appear right away:** close and reopen the app. It also reloads all data every time you return to it.
- **A free Supabase project pauses after about a week with no use.** If that happens, open the Supabase dashboard and click **Restore**. Using the app regularly keeps it awake.
